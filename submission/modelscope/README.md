# 信号实验室 Signal Lab · 配套资产

> **这里没有训练模型。** 作品本体是一个纯前端的电子实验台（原生 JavaScript + Canvas，零依赖、双击即用），全部物理都在浏览器里实时算，不跑任何深度学习推理。这个仓库放的是它**可以被别人复算的那部分**：题库与答案键、仿真试点队列、生成与校验脚本。

## 这里面是什么

| 位置 | 内容 |
| --- | --- |
| `app/js/quiz.js` | 题库生成器与答案键。前测 / 后测各 10 道单选，五块知识点各 2 题；6 道平行题 + 4 道锚题（锚题两卷一字不差）。题目和选项由固定种子生成，跑一遍就能复现 |
| `pilot/` | 仿真试点队列：88 份成绩单（44 名有代号学生 + 6 份匿名卷）、生成器 `make_cohort.js`、校验器 `verify_cohort.js`、报告样例 |
| `docs/` | 效果验证协议、演示脚本、项目说明 |

**`pilot/` 里每一份记录都是合成数据，不是真实学生。** 文件名带 `合成-` 前缀，JSON 里有 `synthetic: true`，报告首行也写着。真人前测 / 后测要按 `docs/效果验证协议.md` 做，做完再替换。

## 为什么值得看一眼

- **题库可复现**：生成器用固定种子，跑一遍出来的卷子跟仓库里的完全一致。锚题在两套卷子之间一字不差，这是前后测对比成立的前提。
- **队列可复算**：`node pilot/verify_cohort.js` 会重新收一遍卷、聚合、出诊断，并断言 44 条性质（含「配对提升 ≠ 前后测平均分直接相减」这条最容易搞错的地方）。
- **答案键核过**：每道题的干扰项都是按常见错法设计的，不是随机数。`app/test/quiz_smoke.js` 的 52 项会验证「每道题至少 3 个选项且不重复」，这条是因为真出过只有两个选项的题。

## 怎么用

```bash
git clone https://github.com/qingchen102/em-signal-lab
cd em-signal-lab
node app/test/quiz_smoke.js      # 题库 52 项
node pilot/verify_cohort.js      # 试点队列 44 项
```

然后在浏览器里打开 `app/index.html`。跑页面本身不需要 node、不需要 pip、不需要联网。
