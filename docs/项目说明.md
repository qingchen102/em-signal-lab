# 信号实验室 Signal Lab · 商业计划书

|  |  |
| --- | --- |
| 项目名称 | 信号实验室 Signal Lab |
| 作品形式 | 软件原型 + AI 应用 |
| 技术栈 | 原生 JavaScript 与 Canvas，无框架、无构建、无第三方依赖 |
| 运行方式 | 双击 `app/index.html`，离线可用，不需要账号 |
| 参赛赛道 | 校园赛道 · 自由命题（示例场景 04 教育） |

电子信息类的学生在《信号与系统》《通信原理》上花的时间不少，公式也推得动，但很少有人真的把参数拧过一遍、看着波形在眼前变形。实验课时间不够，设备要排队，课后又摸不到仪器。信号实验室把信号发生器、示波器、频谱仪、时频图、星座图、阵列测向和多径沙盒做进一个网页，双击就能跑；每调一个参数，右侧面板会说清这个现象对应课本里的哪一句话。同一套东西换个页签，就是教师出练习和看全班错因的工具。

## 一、场景

《信号与系统》的采样定理一般在大二上学期讲。课本上是四行公式加一张频谱搬移示意图，学生点头，考试也能算。问题出现在两周后的实验课。

实验室里一台示波器三十多个旋钮。学生第一次上手，分不清时基和垂直档位各管什么，波形在屏幕上左右跑，调五分钟还在跑。一个助教管二十几个工位，走到第三桌时下课铃响了。这节课学生真正记住的，是“先按一下 Auto”。

另一个场景在宿舍。作业题写着“采样率 1 kHz，输入 1.2 kHz 正弦，画出输出波形”。学生知道要算混叠频率，但脑子里没有画面：1.2 kHz 的信号用 1 kHz 去采，屏幕上到底长什么样，为什么看起来像 200 Hz。手边没有仪器，也没有人能在这一刻告诉他。

这两个场景是同一件事的两头。一头是没有机会亲手拧，另一头是拧完了没人告诉他刚才发生了什么。信号实验室补的是中间这一段。

## 二、用户

| 角色 | 是谁 | 什么时候会打开它 |
| --- | --- | --- |
| 主要用户 | 电子信息、通信工程、自动化专业本科生，大二到研一 | 课前预习、课后复习、实验课前后、考研复习 |
| 第二位用户 | 实验课主讲教师与助教 | 备课做演示波形；课后查全班卡在哪；出分层练习 |
| 第三位用户 | 自学与转专业学生 | 没有实验室准入，也找不到人答疑 |

主用户要的不是一个更好看的课本。他们需要能反复试错，而且试错之后立刻知道错在哪。

教师的需求不同。备课时他们要能当场演示的波形，课后要知道全班卡在哪一道题上，而不只是一个平均分。

自学的人不付费，但他们决定了这东西会不会被主动传播出去。

## 三、痛点

现有的问题可以归成四类。

仪器够不着。真实示波器几十个旋钮，实验课时间有限，学生还没搞明白就该下课。课后没有仪器可练，看教学视频是看别人拧，自己没拧过。

知识是散的。傅里叶在高数里是一个积分，在《信号与系统》里是一个变换，在《通信原理》里是频谱，在《天线原理》里是方向图。四门课四种说法，学生从来没在一件具体的东西上见过它们是同一回事。

反馈太慢。作业一周后批，答疑要排队，视频不能回答“我把窗长调到 512 会怎样”。学习者得不到针对眼前这一帧画面的回应。

教师看不到错法分布。批改只统计对错，不告诉你这道题有六成人选了同一个错项。想分层布置一套练习，手编要一下午。

替代品也各有缺口。MATLAB 和 Python 功能强，但要求会写代码，而且不解释现象；PhET、Falstad 这类在线模拟器做得不错，问题是只能看，学生不用自己判断；MOOC 视频不能交互；商业虚拟仿真实验平台一般按院校授权、部署在校内服务器上，学生课后打不开。

所以缺的不是仿真。缺的是“学生先自己判断、系统再给反馈”这一步。

## 四、方案

### 4.1 五个页签，一台实验台

打开就是五个页签，左边是旋钮，中间是屏幕，右边是知识面板。

| 页签 | 学生能看到什么 | 对应课程 |
| --- | --- | --- |
| 波形与频谱 | 波形、触发、时基与垂直档位；混叠、超量程、触发丢失会自己冒出来；旁边一台频谱仪看谐波 | 信号与系统、电路实验 |
| 阵列测向 | Bartlett、MVDR、MUSIC 三条谱，波束宽度与瑞利限，MUSIC 的超分辨 | 天线原理、阵列信号处理 |
| 时频图 | 非平稳信号；窗长一变，时间分辨率和频率分辨率此消彼长，乘积恒为 1 | DSP、通信原理 |
| 星座图 | 一个符号能塞几个比特；抗噪能力就是点距与噪声圆圈的比例 | 通信原理 |
| 多径沙盒 | 只有一台发射机，阵列却报出好几个方向；楼和发射机可以用鼠标拖 | 电磁场与波、无线信道 |

每改一个参数，三块画面同时更新，不需要点“运行”。

### 4.2 知识面板：每句话都要能当场量出来

方波把带宽限制调到 4，面板不会写“带宽受限导致波形失真”，而是写“现在只剩第 1、3 次谐波，第 5 次起被砍掉，所以边沿变圆”。学生可以切到频谱仪，把那两根谱线数出来。

这类规则一共 29 条，覆盖示波器操作、采样定理、频谱与谐波、阵列、时频、星座和多径。写法统一：先说屏幕上现在是什么，再说为什么，再指出这在哪门课的哪一章讲过，最后给一句可以马上动手验证的建议。

### 4.3 教师端

两个页签。

出练习：勾知识点和难度，一键生成带配图的练习卷与答案页，可以直接打印或存 PDF。每道题的图由实验台自己渲染，和学生在屏幕上看到的是同一套。

看全班：把学生的成绩单 JSON 拖进来，得到配对提升、五个知识点的强弱、每个题型最常见的错法，可导出 CSV 和一段诊断文字。

### 4.4 效果验证

三条路径，可信度从高到低。

第一条是与教科书公式对账。每台仪器都要和闭式解逐档比较，不是看着像就行。星座图的误符号率现场对 M-PSK 与方阵 M-QAM 的解析式，要求每一档信噪比下实测错误数落在理论期望的 4σ 内；多径沙盒验入射角恒等于反射角、起点反射点终点共线、路径长度等于各段之和，以及法向入射 Γ = −0.402、掠入射趋于 −1、自由空间路损 1/L；阵列的三条谱在单信源下峰值位置与真值一致，在相干多径下复现出 MUSIC 报出虚假方向这一现象。目前离线断言 657 项，全部通过。

第二条是工具链路端到端。出题、落盘、收卷、配对统计、错因分布、导出，整条链路走通，另有 44 项断言在校验。

第三条是真人前测后测。前测后测各 10 题，五块知识点各 2 题，其中 4 道锚题两卷完全相同。协议已经写好，还需要拉 5 到 10 位同学跑一次，并访谈 1 到 2 位实验课教师。

## 五、数据口径

现在仓库里的 88 份成绩单是合成的，由固定种子生成，可以重跑、可以核查。它的用途是验证上面第二条链路，不构成教学效果的证据。真人数据按 `docs/效果验证协议.md` 执行，做完之后会如实替换。

这件事在项目说明、报告首行、每一份 JSON 文件里都写明了，不等别人来问。理由很实际：本作品主张“每条结论都带证据、带不确定性”，如果数据来源含糊，这个主张自己就先站不住。

仿真队列里刻意保留了真实课堂一定会有的三类人：6 人只交了前测就再没出现，6 份匿名卷配不上对，2 人前后测同分。结果是把所有人的平均分直接相减得到 +14 个百分点，而只算能配对的 38 人只有 +11.3。教师端会把这个差异指出来，而不是给一个好看的数字。

## 六、技术选择与代价

波形用截断傅里叶级数算，不是画出来的。方波由奇次谐波叠加而成，带宽限制调低，高次谐波是真的被砍掉。时域和频域在代码里共用同一个上限。

采样是真的。示波器按设定的采样率对信号取样，采样率低于两倍信号频率时，屏幕上出现的波形是算出来的，不是做动画做出来的。

频谱用整周期同步 DFT，第 k 根谱线正好是第 k 次谐波，是精确的傅里叶系数。所以方波基波幅度能和 4/π 对上。

多径沙盒没有引第三方射线追踪库。自己写二维镜像法、菲涅尔反射系数和矩形遮挡判断。代价是只做二维、只算到二阶反射；换来的是不用装 Python、不用装 Sionna、不用 GPU，双击就能跑。

AI 助教不是通用聊天框。学生一问，它收到的是一份结构化的现场描述：当前波形参数、采样率、触发电平、谱线、阵列谱、时频窗长、星座噪声、沙盒路径表。所以它能回答“我刚才把窗长调到 512 会怎样”。

整套东西离线优先。信号合成、频谱、阵列、时频、星座、沙盒全部是纯 JavaScript，断网也能跑完整演示。只有 AI 助教需要联网，且是可选功能。

## 七、竞争与替代

| 方案 | 强在哪 | 学生课后能用吗 | 是否要求学生自己判断 |
| --- | --- | --- | --- |
| MATLAB / Python | 计算能力完整，可做研究级仿真 | 要装环境，多数人放弃 | 否，需要自己写脚本 |
| PhET、Falstad 等在线模拟器 | 免费、上手快、动画直观 | 能 | 否，主要靠看 |
| MOOC 与教学视频 | 讲解系统 | 能 | 否，不能交互 |
| 商业虚拟仿真实验平台 | 场景完整，可对接教务 | 通常部署在校内，课后打不开 | 部分 |
| 真实实验设备 | 无可替代 | 不能 | 是，但机会太少 |
| 信号实验室 | 免费、离线、双击即用 | 能 | 是，先判后给反馈 |

真正的差别在最后一列。前面几类都能把现象画给你看，但看完之后学生有没有动脑，没人管。信号实验室的每个预设都要求学生先说出“屏幕上这是什么”，再给解释。

## 八、落地路径

第一条是高校实验教学中心。虚拟仿真实验教学项目每年都有立项和验收，需要能演示、能复现、能统计的交互件。信号实验室可以直接放在实验前的预习环节和实验后的复练环节。

第二条是教材配套数字资源。信号与系统、通信原理这类教材的数字资源包里，正好缺一个能拧的交互件，而不是又一份 PPT。

第三条是教师个人备课，免费开放。这是获客入口，不指望它赚钱。

定价还没定，倾向按院校年度授权或按课程包。第一年不打算收费，目标是把东西放进两到三门课的实验环节，换回真实使用数据和任课教师的背书。成本结构上，静态托管接近零；AI 助教按调用计费，可以让学生填自己的 key，或者由学校统一采购。

## 十、风险与边界

一个人开发，维护带宽有限。当前最缺的不是功能，是真人数据和一线教师的反馈。

沙盒是二维、最多二阶反射。对“多径为什么让测向失效”这一个教学点够用，但不能替代真实射线追踪做覆盖规划。

88 份成绩单是合成的。这一点必须说在前面，不能靠评委自己去发现。

AI 助教依赖外部大模型，离线时自动隐藏，功能降级但仪器部分不受影响。

浏览器兼容以 Chrome 和 Edge 为主，Safari 未做完整测试。
